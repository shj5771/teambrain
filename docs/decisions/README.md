# 설계 결정 기록

TeamBrain을 만들면서 내린 주요 결정과 그 이유를 남긴 문서입니다. 각 문서는 같은 틀을 따릅니다.
**상황**(무엇이 문제였나), **검토한 선택지**, **결정**, **결과**(얻은 것과 감수한 것).

| # | 결정 | 한 줄 요약 |
|---|---|---|
| [0001](0001-connect-dont-rebuild.md) | 메신저도 AI 에이전트도 새로 만들지 않는다 | 이미 잘 만들어진 두 오픈소스 사이의 "팀 기억" 층만 만든다 |
| [0002](0002-integration-point.md) | 연결 지점은 Hermes의 메모리 플러그인 | 다섯 가지 연결 방법을 같은 기준으로 비교했다 |
| [0003](0003-license-boundary.md) | 라이선스 경계를 구조로 지킨다 | AGPL 메신저와는 공개 API로만 통신하고, 우리 코드는 별도 프로세스에 둔다 |
| [0004](0004-one-bot-per-teammate.md) | 팀원마다 봇을 하나씩 둔다 | "나를 학습하는 AI"는 봇 하나를 같이 쓰는 방식으로는 만들 수 없었다 |
| [0005](0005-privacy-fail-closed.md) | 애매하면 기록하지 않는다 | 공개 채널만 기록하고, 판단할 수 없으면 저장하지 않는다 |
| [0006](0006-raw-log-plus-llm-wiki.md) | 원본을 남기고, 위키는 AI가 정리한다 | 지식 체계를 미리 설계하는 대신, 출처가 남는 위키를 자라게 한다 |
| [0007](0007-mcp-read-only.md) | MCP 서버는 기본이 읽기 전용 | 공개인지 알 수 없는 곳에서는 자동으로 기록하지 않는다 |
