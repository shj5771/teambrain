# 0007. MCP 서버는 기본이 읽기 전용

- 상태: 채택

## 상황

메신저 봇만으로는 팀 기억을 쓸 수 있는 곳이 제한된다. 개발자는 편집기 안의 AI(Claude Code, Cursor 등)에게도 "우리 이거 어떻게 하기로 했지?"라고 묻고 싶다.
MCP는 이런 AI 도구들에 기능을 붙이는 표준 방식이라, MCP 서버를 만들면 한 번에 여러 도구를 지원할 수 있다.

문제는 기록이다. 메신저에서는 "공개 채널인가"로 기록 여부를 판단했지만, MCP 클라이언트는 그런 정보를 주지 않는다.

## 결정

- 기본은 **읽기 전용**이다. 팀 검색, 위키 목록, 위키 읽기 세 가지만 제공한다.
- 대화를 자동으로 기록하는 기능은 **만들지 않는다**. [0005](0005-privacy-fail-closed.md)의 원칙(판단할 수 없으면 기록하지 않는다) 그대로다.
- 사용자가 "이거 팀에 공유해줘"라고 할 때를 위한 `team_remember` 도구는 설정(`TEAMBRAIN_MCP_ALLOW_WRITE=1`)으로 켜야만 보인다. 켜더라도 저장되는 것은 메모 한 줄뿐이고, AI의 답변이나 대화 맥락은 저장하지 않는다.
- 표준 라이브러리만으로 구현한다. 설치할 것이 없다.

## 결과

- 얻은 것: 메신저 밖에서도 같은 팀 기억과 위키를 쓸 수 있다.
- 감수한 것: stdio 방식이라 팀 기억 파일이 있는 컴퓨터에서만 동작한다. 원격 접속은 로드맵에 있다.
